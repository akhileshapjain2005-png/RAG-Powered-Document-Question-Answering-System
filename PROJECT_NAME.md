# Project Name: RAG-DocQA

## Full Name
**RAG-DocQA: AI-Powered Document Question Answering System**

## Short Name
**RAG-DocQA**

## Description
An intelligent document question-answering system built with RAG (Retrieval-Augmented Generation) architecture. Upload documents, ask questions, and get AI-powered answers with source citations.

## Why This Name?

- **RAG**: Highlights the core architecture (Retrieval-Augmented Generation)
- **DocQA**: Common abbreviation for "Document Question Answering" - easily searchable
- **AI-Powered**: Emphasizes the AI/ML capabilities
- **Descriptive**: Clearly communicates what the system does
